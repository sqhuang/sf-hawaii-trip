🆘 应急预案

出问题时知道下一步按哪个键。所有故障都有别人的钱兜底(航司 / 卡保险 / 旅游险 / 酒店赔)。

✈️ 航班延误 / 取消

当下立刻做(按顺序):

  1. 不要傻排柜台,那是最慢的
  2. 双线并发:占着柜台队伍,同时在航司 app / 客服电话改签 — 90% 情况下 app 比柜台快 30 分钟
  3. 5+ 小时延误或过夜:主动开口要 hotel + 餐饮 voucher,不问不给
  4. 后段受影响:一次性把后续所有受影响航段全改,别等下一站再处理

本次行程最该警惕的两段:

  • 5/06 AS1072 HNL→ITO 13:35 — 取消备选:同天 AS / Hawaiian Airlines 后续班次
  • 5/09 KE054 → KE2011 ICN 中转只 2h — 全 KE 代码,自动改下一班(可能多过 1 晚 ICN,KE 包酒店)

钱的回路:

  • 美国国内段(UA1175 / AS1072 / AS1091)取消或大延误:DOT 2024 新规必须现金退款,不是 voucher,坚持要现金
  • 长延误 >6h:订机票那张卡的 trip delay insurance 多半含,保留登机牌 + 延误证明
🧳 行李丢失

先安心:真"丢"概率 < 0.5%,95% 是延误 24–72h,几乎都能找回。

真没出来:

  1. 不要离开行李提取大厅 — 出了海关回不来
  2. 找航司的 Baggage Service Office(就在提取大厅出口附近)
  3. 填 PIR (Property Irregularity Report) → 拿 reference number 拍照存档(唯一追踪凭证)
  4. 留酒店地址 — 找到后航司送上门,不用回机场
  5. 主动问 essentials allowance:UA / KE 都有,延误 >24h 给 $50–150/人买必需品,留收据

信用卡 baggage insurance:延误 >6h 一般 $100/天,丢失最高 $2000–3000。

风险排名:5/01 HKG→SFO 国际段 > 5/09 HNL→ICN→HKG > 国内短程

🏨 酒店问题

4 个常见状况 + 怎么处理:

  • 没找到 reservation:拿出离线 PDF 给前台 + 拨预订平台。极端情况要求 walk you to comparable hotel,差价 + 出租车由酒店出
  • 房型给错(SF 那间无障碍特大床+浴缸是合同):坚持原房型,引用预订单条款
  • 早到房间没好:行李寄存 + 留电话/短信通知,出去玩,行业惯例
  • 入住后发现问题(空调/热水/虫/霉):马上下楼或电话,不要等 24h → 要求换房;没空房 → partial refund / 免费升级

Escalate 路径:前台 → Manager on Duty → 预订平台客服 → Booking / TripAdvisor 写 review。经验上写到一半经理就来谈了。

夏威夷特有的两个坑:

  • Resort fee $30–65/晚,check-in 才交,合规收费(Hilton Hawaiian Village 约 $55–65)
  • Incidentals hold $100–200/晚 — 信用卡预授权,2–7 天后释放。绝对不要用 debit 卡,会真冻结余额
